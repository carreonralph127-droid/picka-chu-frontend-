# ⚡ Pikachu Universe

Welcome to **Pikachu Universe**! ⚡

A modern and interactive Pokémon-themed website dedicated to **Pikachu**, the iconic Electric-type Pokémon.

The website features an animated environment with rain, lightning effects, interactive elements, and a clean modern UI.

## ✨ Features

- ⚡ Modern Pokémon-themed UI
- 🐭 Pikachu-focused design
- 🌧️ Animated rain effect
- ⚡ Lightning animation
- 🎵 Background music toggle
- 🖱️ Interactive Pikachu movement
- 🏠 Home section
- 🖼️ Gallery section
- 📖 Pokédex section
- 📩 Contact section
- 📱 Responsive design

## 🛠️ Technologies Used

This project was built using:

- **HTML5**
- **CSS3**
- **JavaScript**
- **Google Fonts**
- **CSS Animations**
- **JavaScript DOM Manipulation**
